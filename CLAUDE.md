# Notes for working on this repository

## Keep the GitHub profile in sync

The README of [LinzN/LinzN](https://github.com/LinzN/LinzN) is the GitHub profile page and mirrors this website: the same projects, descriptions, platforms, libraries and links, just shorter.

Whenever a change here touches what the profile shows – a project added, removed or renamed, a new description, platform, logo path, library, link or package source – make the matching change in `LinzN/LinzN/README.md` in the same session. Purely visual changes (CSS, layout, animations) need no profile update.

## Copy rules

- Plain, human wording – no slogans, no filler, no first person ("I", "my").
- Never mention Plex, and don't compare Ondura with Microsoft 365.
- No references to Duolingo (Parla), 3uTools or MirraFlash (Obsidia).
- Website texts exist in German and English (`{{de}}…{{en}}…{{/}}`); keep both in step. The profile README is English only.
